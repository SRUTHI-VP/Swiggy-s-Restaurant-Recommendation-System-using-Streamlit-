# 🍴 Swiggy Restaurant Recommendation System

## Overview

A content-based restaurant recommendation system built using the Swiggy restaurant dataset. The application recommends restaurants based on user preferences such as **city, cuisine, minimum rating, and maximum cost**.

## Features

- Data Cleaning and EDA
- One-Hot Encoding for city
- Multi-label encoding for cuisine
- Feature Scaling using StandardScaler
- Restaurant ranking using Cosine Similarity
- Interactive Streamlit application

## Recommendation Process

User Preferences  
→ Filter Restaurants  
→ Encode & Scale Features  
→ Create User Vector  
→ Calculate Cosine Similarity  
→ Rank Restaurants  
→ Display Top Recommendations

## Technologies Used

- Pandas
- NumPy
- Scikit-learn
- Streamlit
